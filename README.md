# cheeseweb

A rich, responsive ecommerce experience for **The Cheese Couriers**—an artisan cheese subscription supporting independent makers and reducing food waste.

## Features

- Animated editorial storefront and monthly subscription boxes
- Individual artisan cheese catalogue and product details
- Persistent shopping bag
- Fully simulated secure card checkout
- Animated simulated parcel tracking
- Brand story, impact metrics, and maker profiles
- Responsive desktop, tablet, and mobile design

## Run locally

```bash
npm install
npm run dev
```

## Verify

```bash
npm run lint
npm run build
```

Payments and tracking are simulations for demonstration purposes. No payment details are sent or stored.
